# מימוש מעגן — 15.11.2026

המשתמשת בחרה בחלופת מעגן ואישרה את מימושה באפליקציית Angular.

היקף: מסגרת משותפת עם ניווט RTL בגוון דיו, רשימת בקרות עם סקירה המבוססת על הספירה האמיתית, חלון יצירה/עריכה, עץ תנאים מקונן, סיכום התנאים, תוצאות, מסננים ומצבי מערכת. פלטת מנטה וירוק לפעולות, סגול לקבוצות OR, אדום לסיבות חריגה וירוק למצב ללא חריגות. משתני העיצוב נמצאים ב־`frontend/src/styles.scss`; מסגרת האפליקציה ב־`app.component.ts` וב־`app.component.scss`.

המימוש משמר שמירה והרצה נפרדות, אישורי סגירה והחלפת ישות, תנאים רקורסיביים, שדות תוצאה מהשרת, חיפוש וסינון, מגבלת תוצאות וחזרה לרשימה. נוספו התאמות למסכים צרים, פוקוס נראה וקישור דילוג לתוכן. לא השתנו שירותי API, נתיבים, לוגיקה עסקית, בקאנד או מסד נתונים, ולא הותקנו תלויות. AI נשאר הצעת עיצוב עתידית ואינו מוצג כיכולת זמינה.

דרישות רלוונטיות: UX-01, TECH-06/07, RULE-03/05, RESULTS-01..06 ו־EXEC-05. זהו שינוי עיצובי ואינו משנה את סטטוס השלמת הפונקציונליות במסמך הדרישות.

אימות: `npm.cmd run build` עבר ללא אזהרות תקציב; `npm.cmd test -- --watch=false` עבר — 54 בדיקות בחמישה קבצים. ההרצות בוצעו עם הרשאות מורחבות לאחר שכלי הבנייה נחסם בקריאת נתיבים בסביבה המוגבלת. `git diff --check` עבר. לא בוצע אימות חזותי של Angular בדפדפן, ולכן לא מסומנת השלמת QA חזותי או נגישות מלאה.

לצפייה: מתוך `frontend` הפעילו `npm.cmd start` ופתחו `http://localhost:4200`; שירות ה־API נדרש עבור הנתונים והפעולות כרגיל. תצוגות העיצוב הזמניות הוסרו לאחר בחירת העיצוב ומימושו, לפי בקשת המשתמשת.
